## 4. Architecture Decisions & Brand Alignment

1. **Brand Centralization (`Aurelia Foundation`):**
   - In accordance with Project Owner decisions, all references to the organization use **Aurelia Foundation** with tagline *"Every dollar tracked. Every community verified."*
   - Brand constants are strictly centralized in [`src/lib/brand.ts`](file:///D:/GitHub/bedi-hopewell/src/lib/brand.ts). Internal Bedi repository names are not exposed on the frontend.
2. **Approved Hopewell Variant 2 Palette:**
   - Established in `src/styles/variables.css` and verified via computed DOM values:
     - **Ledger Ink:** `#16241D` (`rgb(22, 36, 29)`)
     - **Canvas:** `#F1EDE1` (`rgb(241, 237, 225)`)
     - **Manifest Gold:** `#C4922B`
     - **Stamp Clay:** `#B8472E`
     - **Line:** `#D8D0BC`
3. **Typography Architecture:**
   - Loaded via `next/font/google` in `src/app/layout.tsx` with font-display swap:
     - `Fraunces`: Variable font (weights 500, 600, 700) bound to `--font-display`.
     - `Inter`: Variable font (weights 400, 500, 600, 700, 800) bound to `--font-body`.
     - `Space_Mono`: Fixed weights (400, 700) bound to `--font-mono`.
4. **Scope Isolation:**
   - No Phase 2 domain datasets or mock data files were authored.
   - No Phase 3 shared UI components, public pages, donation forms, or portal views were implemented.
